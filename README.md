## 🚗 The Business Overview
**RiderOne** is the professional choice for private transportation in the Greater Accra Region. Specializing in high-capacity, executive-level pickups, we bridge the gap between standard ride-hailing and luxury chauffeur services. 

Operating exclusively with a **Toyota Voxy (7-Seater)**, RiderOne is designed for travelers, families, and corporate professionals who prioritize space, climate control, and absolute punctuality.

### 🌟 Core Value Proposition
- **Superior Space**: A genuine 7-seater setup that comfortably handles large groups and heavy luggage.
- **24/7 KIA Reliability**: Specialized Terminal 3 airport transfers with live flight tracking.
- **Executive Comfort**: A pristine, climate-controlled cabin with a professional, owner-operated chauffeur.
- **Transparent Pricing**: Fixed quotes with zero hidden fees and no pre-payment required.

## 💻 Technical Architecture
This platform is built for **Speed, SEO, and Premium Conversion**.

- **Framework**: [Astro 5.0](https://astro.build/) (Static Site Generation for < 1s Load Times).
- **Frontend**: React 18 & Tailwind CSS 3.
- **Motion Engine**: [Lenis](https://lenis.darkroom.engineering/) for Liquid Smooth Scrolling & [GSAP](https://gsap.com/) for cinematic reveals.
- **Booking Engine**: [Formspree](https://formspree.io/) for professional, serverless form handling.
- **Aesthetics**: Custom-built Glassmorphism UI with Magic UI components.

## 🚀 Development & Deployment

### 1. Requirements
- Node.js (Latest LTS recommended)
- Formspree Account (for the `FORMSPREE_URL` endpoint)

### 2. Setup
```bash
# Install dependencies
npm install

# Setup environment variables
echo "FORMSPREE_URL=https://formspree.io/f/your_id" > .env
```

### 3. Local Development
```bash
npm run dev
```

### 4. Production Build
```bash
npm run build
```
