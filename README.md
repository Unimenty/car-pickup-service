# RiderOne Pickup Service Website

A high-performance, SEO-optimized website for a premium one-man car pickup business.

## Tech Stack
- **Astro**: Static site generation for speed and SEO.
- **Tailwind CSS**: Modern, responsive styling.
- **React**: Interactive booking form.
- **Lucide React**: Beautiful icons.

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## Features
- **Hero Section**: Modern design with a floating 3D-effect car image.
- **Booking System**: React-powered form for ride scheduling.
- **Service Highlights**: Clear presentation of transportation options.
- **Mobile Responsive**: Fully optimized for all device sizes.
- **SEO Ready**: Meta tags and Open Graph support included.
